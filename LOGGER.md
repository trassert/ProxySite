# HTTP Request Logger - Документация

## Что это?

Новый аккуратный логгер для HTTP запросов, который избегает спама повторяющихся запросов.

## Как это работает?

### ✨ Особенности

1. **Фильтрация запросов** — Не логирует health-check и статические файлы
2. **Группировка повторов** — Одинаковые запросы группируются в течение 5 секунд
3. **Эмодзи статусов** — ✓ успех, ⚠ редирект, ✗ ошибка
4. **Быстрые ответы** — Показывает время ответа в миллисекундах
5. **Чистый формат** — Никакой лишней информации

### 📊 Пример логов

**Было:**
```
INFO:     188.17.221.74:0 - "GET /api/vote/390 HTTP/1.1" 200 OK
INFO:     188.17.221.74:0 - "GET /api/vote/391 HTTP/1.1" 200 OK
INFO:     188.17.221.74:0 - "GET /api/vote/390 HTTP/1.1" 200 OK
INFO:     188.17.221.74:0 - "GET /api/vote/392 HTTP/1.1" 200 OK
INFO:     188.17.221.74:0 - "GET /api/vote/393 HTTP/1.1" 200 OK
...
```

**Стало:**
```
✓ GET    /api/vote/390                                        200 (15ms) | 188.17.221.74
✓ GET    /api/vote/391                                        200 (12ms) | 188.17.221.74
✓ GET    /api/vote/390                                        200 (11ms) | 188.17.221.74 (+4 similar in 5s)
```

## Настройка

### Пропускаемые пути (не логируются)
```python
SKIP_PATHS = {
    "/static/",
    "/health",
    "/metrics",
    "/ping",
}
```

### Группируемые пути (логируются с подсчётом)
```python
GROUPED_PATHS = {
    "/api/vote/",
    "/api/proxies",
}
```

### Временное окно группировки
```python
GROUP_WINDOW = 5  # секунд
```

## Как добавить ещё пути?

Отредактируй `http_logger.py`:

```python
# Не логировать
SKIP_PATHS = {
    "/static/",
    "/health",
    "/your/new/path",  # ← Добавь сюда
}

# Логировать с группировкой
GROUPED_PATHS = {
    "/api/vote/",
    "/api/your/endpoint/",  # ← Или сюда
}
```

## Где логи?

- **Консоль (stderr)** — В реальном времени для разработки
- **Файл** — `logs/proxyhub.log` (с ротацией по размеру и сроку)

## Отключение логирования для конкретного пути

```python
# В http_logger.py добавь путь в SKIP_PATHS
SKIP_PATHS = {
    "/static/",
    "/health",
    "/api/metrics",  # Не будет логироваться
}
```

## Часто задаваемые вопросы

**Q: Как вернуть старое логирование?**
A: Удали `http_logger.py` из импортов и middleware в `main.py`

**Q: Можно ли логировать всё подробнее?**
A: Измени уровень в `config.toml`:
```toml
[logging]
level = "DEBUG"
```

**Q: Как посчитать реальное количество запросов?**
A: Смотри файл логов (`logs/proxyhub.log`) — там полная информация без группировки
